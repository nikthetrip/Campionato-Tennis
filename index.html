Come Pubblicare l'App Online Gratis

Puoi pubblicare questo file direttamente su internet così che tutti e 6 possiate vederlo dallo smartphone.

Opzione A: GitHub Pages (Gratis & Consigliata)

  1. Crea un file chiamato index.html e incollaci tutto questo codice.
  2. Crea un repository gratuito su GitHub.com (es. campionato-tennis).
  3. Carica il file index.html nel repository.
  4. Vai in Settings ➔ Pages del repository, imposta il ramo su main e salva.
  5. Dopo 1 minuto avrai il tuo link pubblico tipo: https://tuousername.github.io/campionato-tennis!

Opzione B: Streamlit / Python (Se vuoi usare Streamlit)

Se desideri la versione native Python Streamlit per la Streamlit Community Cloud, crea un file app.py con questo script wrapper:

import streamlit as st
import streamlit.components.v1 as components

st.set_page_config(page_title="Tennis 6 Amici", layout="wide")

# Carica l'applicazione HTML integrata
with open("index.html", "r", encoding="utf-8") as f:
    html_code = f.read()

components.html(html_code, height=900, scrolling=True)

Opzione C: Netlify / Vercel

Trascina semplicemente la cartella contenente questo file index.html su app.netlify.com/drop per ottenere un link pubblico in 5 secondi senza nemmeno registrarti!
